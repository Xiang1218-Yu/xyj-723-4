### API 通信机制

前端通过统一的 [request.ts](file:///Users/tog/Desktop/code/gsb/gsb-723/xyj-723-4/xyj-723-4_Charmander/apps/web-antd/src/api/request.ts) 客户端与后端通信，具备以下特性：

- **JWT Token 认证**：Bearer Token 自动携带，支持刷新Token机制
- **多租户支持**：请求头自动携带 `tenant-id` 和 `visit-tenant-id`
- **API 加解密**：AES/RSA 加密请求体、解密响应体，密钥可配置
- **统一响应处理**：自动解析 `{code: 0, data: {...}, msg: ""}` 格式
- **错误拦截**：401 自动刷新Token，Blob响应错误解析
- **国际化**：请求头携带 `Accept-Language`
- **文件上传下载**：封装 upload/download 方法
- **SSE 支持**：Server-Sent Events 流式响应

API 基础配置：
```
后端地址: http://127.0.0.1:48080
API前缀: /admin-api
代理配置: vite.config.ts 中配置 /admin-api 代理
```

## 快速开始

### 环境要求

- Node.js >= 22.18.0 或 >= 24.0.0
- pnpm >= 11.0.0

### 安装与运行

```bash
# 安装依赖
pnpm install

# 启动开发服务器（Ant Design Vue 版本）
pnpm dev:antd

# 或启动其他版本
pnpm dev:ele       # Element Plus
pnpm dev:naive     # Naive UI
pnpm dev:tdesign   # TDesign

# 构建生产版本
pnpm build:antd
```

### 默认账号

- 用户名：`admin`
- 密码：`admin123`

### 环境变量配置

在 [.env.development](file:///Users/tog/Desktop/code/gsb/gsb-723/xyj-723-4/xyj-723-4_Charmander/apps/web-antd/.env.development) 中配置：

```bash
# 后端服务地址
VITE_BASE_URL=http://127.0.0.1:48080
# API 前缀
VITE_GLOB_API_URL=/admin-api
# 租户开关
VITE_APP_TENANT_ENABLE=true
# API 加解密开关
VITE_APP_API_ENCRYPT_ENABLE=true
# 文件上传类型
VITE_UPLOAD_TYPE=server
```
