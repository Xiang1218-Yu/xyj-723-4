# 芋道管理系统（中台框架）

> 基于 [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin) v5.7.0 的企业级中后台管理系统前端框架，采用 pnpm + Turborepo Monorepo 架构，内置 15+ 业务子系统，对接 [芋道 yudao-cloud](https://github.com/YunaiV/yudao-cloud) Spring Boot 后端。

### 请求处理流程

```
页面操作 → API 函数 → RequestClient
                          │
                    ┌─────┴──────┐
                    │ 拦截器链    │
                    ├────────────┤
                    │ 1. 请求拦截 │  → 注入 Authorization (Bearer Token)
                    │            │  → 注入 tenant-id (多租户)
                    │            │  → 注入 visit-tenant-id
                    │            │  → AES 加密请求体 (可选)
                    ├────────────┤
                    │ 2. 响应拦截 │  → AES 解密响应体
                    │            │  → Blob 错误解析 (下载场景)
                    │            │  → 统一格式提取 {code, data, msg}
                    │            │  → Token 过期自动刷新
                    │            │  → 错误消息提示
                    └────────────┘
                          │
                    后端 API (:48080/admin-api)
```

关键实现参考：[request.ts](apps/web-antd/src/api/request.ts)

### 1. 系统管理（system）

**功能描述：** 提供平台级别的基础管理能力，包括用户账号管理、角色权限分配、菜单动态路由、组织架构（部门/岗位）、多租户管理、数据字典、地区管理、站内信通知等。是整个中台系统的权限与组织基础。

### 2. 基础设施（infra）

| 子模块 | 功能说明 | API 路径前缀 |

## 快速开始

### 环境要求

- **Node.js**: `^22.18.0 || ^24.0.0`
- **pnpm**: `>= 11.0.0`

### 安装与启动

```bash
# 安装依赖
pnpm install

# 启动主版本（Ant Design Vue）
pnpm dev:antd
# 访问 http://localhost:5666

# 启动其他 UI 版本
pnpm dev:ele       # Element Plus
pnpm dev:naive     # Naive UI
pnpm dev:tdesign   # TDesign
```

### 环境配置

修改 [.env.development](apps/web-antd/.env.development) 配置后端地址：

```env
# 后端 API 地址（默认芋道后端 :48080）
VITE_BASE_URL=http://127.0.0.1:48080
VITE_GLOB_API_URL=/admin-api
```

### 默认账号

```
用户名: admin
密码: admin123
```
